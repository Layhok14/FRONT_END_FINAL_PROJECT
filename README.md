# Thnam Front End

Updated Vite + React project for a calm, minimal medication tracker experience.

## Included
- Landing page before login/signup
- Login and signup for patient or caregiver
- Improved home screen with minimal first view
- Medication detail popup with marked image upload area
- Checkout popup with multi-select medicine updates
- Weekly calendar with synthetic local-storage data
- History, caregivers, and full settings/profile flow
- Profile image upload, editable fields, password change, and logout
